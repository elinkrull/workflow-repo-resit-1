# Workflow Resit 1 Repo

## Built with

- HTML

- CSS

- JavaScript

## Goal: To learn how to use useful problem-solving tools, methods and strategies that accumulate over time.

## Tech Stack

- Vite (unit testing: Vitest)

- Playwright (end-to end testing)

- TailwindCSS (styling)

- ESLint + Prettier (linting and formatting)

- Husky + lint-staged (git hooks)

## Installing

- Clone the repo

<pre></pre>

Project Setup

## Install dependencies

<pre>npm install</pre>

## Development

Run Tailwind in watch mode to build CSS:

<pre>npm run dev</pre>

## Live website:

Open the site in a browser by using Live Server VS Code extension

Testing

## Unit tests (Vitest)

Run all unit tests:

<pre>npm run test</pre>

End-to-end tests (Playwright)

-The end-to-end tests (Playwright) need the site to be running locally before running the tests.

## Run all Playwright tests:

<pre>npx playwright test</pre>

## Run Playwright in UI mode (debugging):

<pre>npx playwright test --ui</pre>

## View last Playwright HTML report:

<pre>npx playwright show-report</pre>

Code Quality

## Linting

Check code style:

<pre>npm run lint</pre>

## Prettier & ESLint auto-fix

Automatically run Prettier + ESLint on staged files before commit:

<pre>npx lint-staged</pre>
